# OAB Severity Classification using Machine Learning

An explainable machine learning framework for classifying Overactive Bladder (OAB) severity using questionnaire-based data.

## Project Overview

This project explores machine learning models for classifying OAB severity into three categories:

- No OAB
- Mild OAB
- Moderate OAB

The project includes data preprocessing, feature analysis, class-balancing using SMOTE, machine learning model comparison, model evaluation, and explainable AI using SHAP and LIME.
